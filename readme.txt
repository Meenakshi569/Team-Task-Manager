Project Title: Team Task Manager

Description:
This is a MERN stack web application that allows admins to create projects and assign tasks to users.

Features:
- User Authentication (JWT)
- Role-based access (Admin & Member)
- Task creation and assignment
- Task status update
- Dashboard with task stats

Tech Stack:
- MongoDB
- Express.js
- React.js
- Node.js

How to Run:
1. Clone the repository
2. Run backend: npm install && npm start
3. Run frontend: npm install && npm run dev
